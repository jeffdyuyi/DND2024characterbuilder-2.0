![1784945770972](image/主界面与角色卡视觉重构及双端响应式适配方案/1784945770972.png)# 主界面与角色卡视觉重构及 PC/Mobile 双端响应式适配方案

## 1. 概述与优化目标

目前主界面呈现偏向极简浅色系统软件，存在**奇幻沉浸感不足**以及**PC端两侧大面积留白/手机端缺乏纵向优化**的问题。

本方案旨在借鉴 D&D Beyond 等顶尖跑团工具的精髓（参考图3），全面打造**“黑金奇幻风格 (Dark Fantasy Aesthetics)”**，并建立**高信息密度的 PC 端 Dashboard 布局**与**手机端纵向优先单手操作体验**的无缝响应式体系。

---

## 2. 设计系统与 Design Tokens 规范

扩展现有的 TailwindCSS / CSS Variables，建立“跑团奇幻黑金”设计系统。

### 2.1 颜色系统 (Color Tokens)

| Token 名称                 | CSS 变量 / 十六进制值             | 用途与场景                         |
| :------------------------- | :-------------------------------- | :--------------------------------- |
| **bg-fantasy-primary**     | `#0D0E15` (深暗黑铁)              | 整体应用主背景色                   |
| **bg-fantasy-secondary**   | `#161824` (暗玄武岩)              | 卡片、面板、抽屉背景色             |
| **bg-fantasy-tertiary**    | `#202334` (浅石板灰)              | 输入框、次级卡片、选中态背景       |
| **border-gold-accent**     | `#C5A059` / `#D4AF37` (暗金/古金) | 核心边框、强调线、高亮卡片边框     |
| **border-dark-steel**      | `#2A2D40` (黑铁边框)              | 次要分割线、常态卡片边框           |
| **text-fantasy-primary**   | `#F0E6D2` (羊皮纸白)              | 标题、主要文字                     |
| **text-fantasy-secondary** | `#A0A5C0` (石板银灰)              | 副标题、说明文字、未选中态         |
| **accent-blood-red**       | `#E63946` / `#B22222` (龙焰红)    | 生命值(HP)、危险警告、主要动作按键 |
| **accent-arcane-blue**     | `#3A86FF` / `#4CC9F0` (奥术蓝)    | 法术位、魔法资源、信息提示         |

### 2.2 字体与材质质感 (Typography & Textures)

1. **字体栈**：
   - **标题/数值 (Headers/Stats)**：`Cinzel`, `MedievalSharp`, `Georgia`, serif (奇幻衬线字体)
   - **正文/技能列 (Body/Tables)**：`Inter`, `system-ui`, sans-serif (高清晰度无衬线字体)
2. **视觉质感 (Textures & Glow)**：
   - **微亮发光 (Arcane Glow)**：`box-shadow: 0 0 15px rgba(212, 175, 55, 0.15);` (用于 Hover 态或选中态)
   - **边框纹理**：采用 `1px solid border-gold-accent` 搭配 4px 圆角或微切角（Fantasy Bevel Style）。

### 2.3 响应式断点 (Responsive Breakpoints)

- **Mobile (手机竖屏)**：`< 768px` (纵向优先、单列流、Tabs 拆分、底部抽屉)
- **Tablet (平板/窄屏)**：`768px ~ 1199px` (双列网格、抽屉式侧栏)
- **Desktop (PC宽屏)**：`≥ 1200px` (3栏多块 Dashboard 全屏平铺、高信息密度)

## 3. 分页面响应式布局架构

### 3.1 主界面 / 角色库 (Home Library)

#### PC 宽屏 (`≥ 1200px`)

- **自适应卡片网格 (Fluid Card Grid)**：采用 `grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`，在 1920px 下自动展示 4~5 列角色卡片，彻底消除左右留白。
- **左侧与顶部功能控制区**：
  - **顶部**：吸顶黑金工具栏，包含搜索框、职业/等级/规则套件（2014/2024）筛选器、排序按钮。
  - **新建角色卡片**：固定在网格第一位，暗金虚线边框，Hover 时展示金色微光。

#### 手机竖屏 (`< 768px`)

- **纵向单列卡片流**：卡片宽度 `100%` 纵向排列，充分利用手机高度。
- **底部悬浮新建按钮 (FAB - Floating Action Button)**：右下角固定圆角金/红按钮 `+ 新建角色`，方便单手大拇指触控。
- **顶部吸顶搜索栏**：折叠式搜索与筛选。

### 3.2 角色卡与创建器 (Character Sheet & Builder)

#### PC 宽屏 (`≥ 1200px`) — 3栏 Dashboard 布局 (借鉴图3)

```
+-----------------------------------------------------------------------------------+
| Top Navigation: 角色名, 种族·职业·等级, 快捷操作 (长休/短休/保存/导出)              |
+-------------------+-----------------------------------+---------------------------+
| [左栏: 属性与技能]  | [中栏: 战斗核心与动作]            | [右栏: 装备与特性]         |
| 1. 6大属性模块     | 1. 生命值 (HP/Temp HP) & 护甲(AC) | 1. 种族/职业特性 (Traits) |
|    (STR/DEX...)   | 2. 先攻 (Initiative) & 熟练加成   | 2. 装备与背包装备         |
| 2. 20项技能检定表 | 3. 主要攻击/动作 (Attacks/Actions)| 3. 专长 (Feats)           |
|    (带骰子快捷图标)| 4. 法术位与法术列表 (Spells)      | 4. 背景与笔记 (Notes)     |
+-------------------+-----------------------------------+---------------------------+
```

#### 手机竖屏 (`< 768px`) — 吸顶 Header + 完整 9 大 Tab 横滑导航 + 底部抽屉 (Bottom Sheet)

1. **顶部吸顶状态栏 (Sticky Compact Bar)**：
   - 滚动页面时保持固定在最上方，实时显示：`角色名 | HP: 20/20 | AC: 15 | 先攻: +2`。
2. **完整 9 大细致 Tab 横向滑动导航 (Full 9-Tab Touch Navigation)**：
   - **完全保留现有的 9 大细分 Tab**，避免粗暴合并导致信息推叠或遗漏：
     1. 🛡️ **主面板**：战斗核心、生命值、护甲、攻击与主要动作。
     2. ✦ **法术**：已知/准备法术列表、法术格管理、法术DC与攻击加值。
     3. 🧬 **种族**：种族特性、特质描述与源质能力。
     4. ⚔️ **职业**：职业特性、子职业能力、资源池（如狂暴/筹策）。
     5. 📖 **背景**：背景能力、起始专长与语言熟练。
     6. 🏆 **专长**：已选专长列表及其机械效果。
     7. 🎒 **物品**：装备、随身物品、负重与金币。
     8. 👤 **档案**：角色外观、阵营、性格与盟友。
     9. 🗺️ **冒险**：跑团战役日志、经验值 (EXP) 与金钱收益。
   - **触控优化**：手机端支持导航栏平滑手势横滑（Horizontal Scroll Bar），当前选中的 Tab 呈现暗金高亮；同时支持下拉菜单快速切换 Tab。
3. **底部抽屉 (Bottom Sheet)**：
   - 点击技能/法术/装备/特性详情时，从手机底部升起羊皮纸风格抽屉，展示完整规则文本与投掷选项，单手下拉即可关闭。

## 5. 审核确认结论

1. **视觉风格**：采纳黑金奇幻 Dark Fantasy 主题（参考图3）。
2. **Tab 导航架构**：**完全保留 9 大细致 Tab 架构**（主面板、法术、种族、职业、背景、专长、物品、档案、冒险），手机端采用触控横滑+暗金高亮定位，确保信息全面零遗漏。
