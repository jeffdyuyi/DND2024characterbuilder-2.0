# 角色卡手动覆盖与字段计算规范 (Manual Override & Sheet Calculation Spec)

> **版本**：v2.0 (2026-09)  
> **定位**：明确角色卡字段在“规则自动计算”与“用户手动控制”之间的优先级契约、可覆盖字段清单及双轨规则约束。整合并替代原覆盖总结与卡面内容整理文档。

---

## 一、三层数据流契约 (Three-Layer Flow)

所有展示在角色卡面的核心数值必须遵循以下严格数据流向：

```text
[Layer 1: Rules Engine (Computed)] 
   纯函数根据基础配置与 5etools/Overlay 算出的标准规则值
                 │
                 ▼
[Layer 2: Manual Overrides (State)]
   存储于 CharacterState.manualOverrides 的用户显式输入
                 │
                 ▼
[Layer 3: View Adapter (Final Presentation)]
   合并逻辑：Final = (Manual !== undefined) ? Manual : Computed
```

### 1.1 偏离状态监控与标记契约

- **正常态 (`computed`)**：当没有手动输入时，卡面展示 Computed 值，无编辑标记。
- **覆盖态 (`overridden`)**：当存在有效的 Manual 值时，卡面展示 Manual 值，并在对应数值旁常驻显示 `✎` 标记，Tooltip 显示 `规则计算值: X`。
- **一键重置 (`reset`)**：每个被覆盖的字段旁提供 `↺` 按钮，点击后将该字段从 `manualOverrides` 中移除，卡面瞬时回退至 Computed 值。

## 二、支持手动覆盖的字段白名单 (Field Whitelist)

| 字段标识 | 关联展示项 | 规则计算源 (Computed Source) | 手动覆盖行为与边界说明 |
|---|---|---|---|
| `abilityScores.[str/dex...]` | 核心六维属性 | 基础购点/骰点 + 种族/背景加值 + 专长加值 | 允许直接锁定或微调最终总值，自动联动重新计算调整值与下属技能。 |
| `armorClass` | 护甲等级 (AC) | 10 + 敏捷修正 / 护甲基值 + 盾牌 + 无甲防御特性 | 允许直接覆盖为固定值（例如房规法术加值或特殊战场环境）。 |
| `maxHp` | 最大生命值 | 1级满骰 + 后续掷骰/均值 + 体质修正 * 等级 | 允许手动修改最大上限（配合 DM 战役奖励或特殊惩罚）。 |
| `speed` | 步行速度 (尺) | 种族基础速度 (通常30尺) + 职业特性 (如武僧/野蛮人) | 允许直接覆盖最终速度数值。 |
| `initiativeBonus` | 先攻修正 | 敏捷修正 + 特长加值 (如警觉) | 允许单独增减先攻总加值。 |
| `proficiencyBonus` | 熟练加值 (PB) | `ceil(1 + level / 4)` | 允许临时提升或降低 PB。 |
| `spellSlotsMax.[1-9]` | 各环阶法术位上限 | 施法者等级进度表 | 允许增加或减少特定环位的最大法术槽数量。 |
| `attunementLimit` | 同调装备上限 | 基础固定为 3（奇械师特性可提升至4/5/6） | 允许手动覆盖同调上限（例如特定神话战役或房规扩充）。 |
| `skillBonus.[skillName]` | 特定技能最终加值 | 属性修正 + PB (单倍/双倍) | 允许输入额外加值（例如战役道具的常驻技能加值）。 |

## 三、双轨规则下的手动开关约束 (2014 vs 2024)

### 3.1 背景属性加值控制 (Background ASI Manual Switch)
- **2024 规则基准**：属性加值由背景指定的三维属性中分配（+2/+1 或 +1/+1/+1）。
- **强制手动开关**：必须在背景页面提供 **“自定义属性加值 (Manual ASI)”** 开关。开启后，允许玩家将这 3 点属性自由分配到任意六维属性上，不可强制锁定死在背景预设的三项中。

### 3.2 魔法装备同调控制 (Attunement Constraint)
- **同调对象范围**：仅限制**带有“需要同调 (Requires Attunement)”标记的魔法物品**。
- **严禁过度限制**：绝不可限制普通装备、非同调魔法物品的总装备数量。
- **同调超限处理**：当已同调物品数量 > 当前同调上限时，卡面应呈现黄色警告提示，但不阻断用户保存和查看。

### 3.3 专长槽位与学派限制
- **专长槽位自由度**：除了标准 4/8/12/16/19 级获得的 ASI/专长外，允许用户手动“添加额外专长槽”（用于 DM 剧情奖励）。
- **法术自由配置**：施法者列表默认按照职业法表过滤，但必须提供“允许选择全法术/跨职法术”的手动调试开关。
