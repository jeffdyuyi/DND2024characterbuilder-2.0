# 职业诊断根因分类与首轮修复记录

日期：2026-10-09。完成完整清单、按目标去重分类和身份关联根因的修复。其余上游异常及来源范围问题等待用户确认；不宣称全量装配完成。

## 实际改动

- 审计保存全部引用失败的所属职业/子职业 ID、原始 UID、引用位置、文件及修订；继承警告保存完整复制目标、类别和文件，不再只保留抽样。
- `scripts/classify-class-audit.mjs` 对显式捕获的审计批次分类；有效 UID 按默认来源、父身份、子职业、等级和特性来源去重；异常 UID 按拥有者及原始文本归组。重复引用的位置仍保留。
- `classAliases.ts` 由上游中英文记录、唯一完整 `_copy` 身份、完整匹配的子职业引用树建立来源限定的别名。拒绝多候选、不同父来源、已有短名身份冲突及不完整引用树；没有职业/特性 ID 表、前缀猜测或机器翻译。
- 同一身份模型用于跨文件复制及 Catalog 特性引用。成功复制记录保留身份关联依据；失败复制保留原始 `_copy` 目标，便于依赖追查。
- 审计补充官方法术依赖，与 `CatalogLoaderService.init()` 中先加载官方法术、后加载 Homebrew 的现有顺序一致。运行时调度未因此改动。
- 上游下载批次及完整原始文档保存在被 Git 忽略的 `scratch/class-audit/`，仅供验收回放，不作为运行时本地语料兜底。

## 现存限制与待确认项

1. UID 异常来自两个文件：
   - `class/Unknown; Mech Pilot.json`：只有名称引用，`Ability Score Improvement` 和 `Universal Upgrade` 重复出现但 UID 没有等级。不能根据数组顺序擅自赋予等级。
   - `subclass/Esquizofrenia Coletiva com Amigo; Art Domain.json`：`Channel Divinity: Divine Inspiration|PHB|Art|ECCAAD|2` 缺少正常子职业 UID 所需字段。
2. 64 个特性目标涉及 `UAClassFeatureVariants`、`UASorcererAndWarlock`、`UA2020SubclassesPt2`、`UAModifyingClasses`、`UASorcerer`、`UARevisedSubclasses`、`UAGiantSoulSorcerer`、`UA2020PsionicOptionsRevisited`、`UALightDarkUnderdark`、`UAWaterborneAdventures`。本轮当前官方分卷与 Homebrew 职业批次未提供这些目标；尚未证明同仓其他目录或历史修订没有对应内容。
3. 7 个复制目标涉及当前批次未提供的 UA 子职业来源，详见完整分类目标。不能用正式出版版本代替 UA 版本。
4. `Orchard Origin` 的复制引用与同来源、同父级、同短名的当前 `Orchard Origin, Reflourished` 完整名称不一致。文件为 `subclass/Rain-Junkie, DXHHH101; Orchard Origin Sorcerer, Reflourished .json`。目标条目已载入，不能继续归为“文件没下载”；是否允许建立旧名称别名，需要确认。
5. 选择语义诊断没有在本轮处理；没有浏览器建卡及真实角色存档验收。用户存档、缓存和既有工作区改动未清理。
