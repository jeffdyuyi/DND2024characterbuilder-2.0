# 职业引用与来源归属修复验收记录

日期：2026-10-09。本轮仅处理职业特性引用、子职业父来源归属及其身份/存档联动。

## 实际改动

- `classReferences.ts` 按 5etools UID schema 解析职业/子职业特性引用：空父来源默认 PHB，保留独立特性来源，忽略末尾展示字段。中英文别名由已注册原始条目建立，不按职业或特性 ID 编写字典。
- `classAssembly.ts` 按父职业名称别名及 `classSource` 选择子职业；允许子职业出版物与父职业来源不同，但必须有相符的父关系。跨来源特性按引用显式指定的来源关联，不用当前父职业版本替换引用版本。
- 子职业 Catalog ID、特性 ID 和 `_copy` 索引纳入父来源；特性还保留等级和子职业来源，避免同名跨版本记录被覆盖。省略父字段的复制引用只接受唯一候选，歧义记录诊断。
- 子职业检索的规则版本由父来源判断，保留上游对新版父职业的显式旧书源适配。
- 旧子职业 ID 根据父职业来源消歧迁移；未知/歧义引用及旧快照保留。已存在的异版本稳定 ID 不自动替换。
- 审计中共用一次构建的引用索引，不加入渲染热路径的全量诊断。
